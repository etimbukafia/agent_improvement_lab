# Enterprise Enterprise Agent Improvement Lab v0.1 Non-Goals

The first enterprise release must stay focused.

Do not build these before the core enterprise improvement loop works.

## Out of scope

- arbitrary executable code generation;
- autonomous production deployment;
- automatic promotion without human approval;
- distributed evaluation infrastructure;
- Kubernetes-specific integrations;
- full SaaS multi-tenancy;
- advanced web dashboard;
- production canary orchestration;
- real-time production monitoring platform;
- sophisticated ML failure clustering;
- generalized autonomous multi-agent optimization;
- model fine-tuning;
- reinforcement learning;
- owning production runtime execution;
- replacing Enterprise Agent Harness;
- business opportunity discovery;
- unrestricted self-modification;
- copying raw enterprise data into the Lab when references or safe summaries are enough.

## Why these are excluded

These features add large operational, security, or product scope.

They are not required to prove the core product.

The v0.1 goal is controlled evaluation and improvement of enterprise agents.

The first release must prove that the system can:

1. evaluate an enterprise agent;
2. find a meaningful failure;
3. explain the likely cause with evidence;
4. propose a bounded change;
5. build a candidate;
6. evaluate the candidate;
7. compare it with the baseline;
8. detect regressions;
9. produce promotion evidence;
10. require a human decision.
